# 🌶️ Chuijhal Mart (চুইঝাল মার্ট) — সেটআপ ও প্রোডাকশন গাইড

এই ফোল্ডারে আপনার **Chuijhal Mart**-এর পূর্ণাঙ্গ প্রোডাকশন-রেডি সিঙ্গেল-পেজ ই-কমার্স ওয়েবসাইট এবং Google Sheets ব্যাকএন্ড স্ক্রিপ্ট রয়েছে।

---

## 📁 ফাইল পরিচিতি
1. `index.html` — আল্ট্রা-প্রিমিয়াম সেলস ল্যান্ডিং পেজ (সব ইমোজি মুক্ত, উজ্জ্বল গোল্ডেন ভেক্টর আইকন, অফিশিয়াল WhatsApp ও Messenger লোগো, বাংলা নম্বর সাপোর্ট এবং রিয়েল-টাইম ভ্যালিডেশন সহ)।
2. `logo.jpg` — আপনার অফিশিয়াল প্রিমিয়াম ব্র্যান্ড লোগো।
3. `banner.jpg` — আপনার অফিশিয়াল ব্র্যান্ড ব্যানার।
4. `Code.gs` (বা `Code (1).gs`) — Google Sheets-এ ব্যবহারের জন্য সম্পূর্ণ ব্যাকএন্ড কোড (অর্ডার সংরক্ষণ, ডুপ্লিকেট রোধ, ড্রপডাউন স্ট্যাটাস এবং স্বয়ংক্রিয় ইমেইল নোটিফিকেশন)।

---

## 🚀 স্টেপ-বাই-স্টেপ সেটআপ (মাত্র ৫ মিনিট)

### ধাপ ১: Google Sheet তৈরি ও স্ক্রিপ্ট পেস্ট
1. আপনার ব্রাউজারে [Google Sheets (sheets.new)](https://sheets.new) ওপেন করুন।
2. শিটের নাম দিন: **Chuijhal Mart Orders & Settings**।
3. উপরের মেনু থেকে **Extensions (এক্সটেনশন)** > **Apps Script** এ ক্লিক করুন।
4. স্ক্রিপ্ট এডিটরে আগের ডিফল্ট কোডটুকু মুছে দিন।
5. এই ফোল্ডারের `Code.gs` ফাইলের সম্পূর্ণ কোড কপি করে এখানে পেস্ট করুন।
6. উপরের টুলবার থেকে **Save (💾 আইকন বা Ctrl + S)** চাপুন।

### ধাপ ২: একবার Setup ফাংশন রান করুন
1. উপরের টুলবারে **"Run"** বাটনের পাশে ফাংশন ড্রপডাউন দেখতে পাবেন।
2. ড্রপডাউন থেকে **`setup`** নির্বাচন করুন এবং **"Run"** বাটনে ক্লিক করুন।
3. প্রথমবার গুগল অনুমতি চাইবে (**Authorization Required**):
   - **Review Permissions** এ ক্লিক করুন।
   - আপনার গুগল অ্যাকাউন্ট নির্বাচন করুন।
   - **Advanced** লিংকে ক্লিক করুন।
   - নিচে **"Go to Untitled project (unsafe)"** এ ক্লিক করুন।
   - **Allow** বাটনে ক্লিক করুন।
4. রান সম্পন্ন হলে আপনার Google Sheet-এ গেলে দেখতে পাবেন দুটি সুন্দর ফরম্যাট করা ট্যাব তৈরি হয়ে গেছে:
   - **Settings** (দাম, ডেলিভারি চার্জ, ছবি ও ফোন নম্বর পরিবর্তনের জন্য)
   - **Orders** (সব নতুন অর্ডার স্বয়ংক্রিয়ভাবে জমা হওয়ার জন্য)

### ধাপ ৩: Web App হিসেবে Deploy করুন
1. Apps Script এডিটরের উপরে ডানদিকের নীল **Deploy** বাটনে ক্লিক করে **New deployment** বেছে নিন।
2. বাম পাশের গিয়ার (⚙️) আইকন থেকে **Web app** সিলেক্ট করুন।
3. নিচের সেটিংসগুলো দিন:
   - **Description:** `Chuijhal Mart Production v1`
   - **Execute as:** `Me (আপনার ইমেইল)`
   - **Who has access:** `Anyone` *(খুব গুরুত্বপূর্ণ! এটি "Anyone" না দিলে ওয়েবসাইট থেকে অর্ডার আসবে না)*
4. **Deploy** বাটনে ক্লিক করুন।
5. Deployment সফল হলে আপনি একটি **Web app URL** পাবেন (যার শেষে `/exec` থাকবে)। URL-টি কপি করুন।

### ধাপ ৪: `index.html`-এ URL বসান
1. আপনার `index.html` ফাইলটি যেকোনো কোড এডিটরে খুলুন।
2. লাইন ৩৩৭-এ যান:
   ```javascript
   const APPS_SCRIPT_URL = "";   // Apps Script Web App URL (.../exec)
   ```
3. উদ্ধৃতিচিহ্নের ভেতরে আপনার কপি করা Web App URL-টি পেস্ট করুন:
   ```javascript
   const APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb.../exec";
   ```
4. ফাইলটি সেভ করুন। ব্যস, আপনার ওয়েবসাইট সম্পূর্ণ লাইভ ও ফাংশনাল!

## ⚙️ পণ্যের দাম ও ডেলিভারি চার্জ কীভাবে পরিবর্তন করবেন?
আপনার কোনো কোড বা ওয়েবসাইট এডিট করতে হবে না!
শুধুমাত্র Google Sheet-এর **Settings** ট্যাবে যান:
- **offerPrice**: আজকের অফার মূল্য (যেমন: ৯৯৯)।
- **regularPrice**: রেগুলার মূল্য (যেমন: ১২০০)।
- **deliveryDhaka**: ঢাকা সিটির ডেলিভারি চার্জ (যেমন: ৮০)।
- **deliveryKhulnaJashore**: যশোর ও খুলনার ডেলিভারি চার্জ (যেমন: ৬০)।
- **deliveryNationwide**: সারা বাংলাদেশের ডেলিভারি চার্জ (যেমন: ১২০)।
- **whatsapp**: আপনার WhatsApp নম্বর (যেমন: `8801833600707`)।
- **notifyEmail**: আপনার ব্যক্তিগত ইমেইল দিন (নতুন অর্ডার আসলে সাথে সাথে বিস্তারিত সহ সুন্দর ইমেইল চলে যাবে)।
- **pixelId**: মেটা (ফেসবুক) পিক্সেল আইডি দিলে স্বয়ংক্রিয়ভাবে ফেসবুক ট্র্যাকিং চালু হয়ে যাবে।
- **offerEndsAt**: বিশেষ কোনো ক্যাম্পেইনের নির্দিষ্ট শেষ সময় দিতে চাইলে (যেমন: `2026-12-31T23:59:00+06:00`), অন্যথায় সাইটে সারাক্ষণ স্বয়ংক্রিয় এভারগ্রিন লুপিং কাউন্টডাউন টাইমার সচল থাকবে।
